Listening test

What this is

A short test of one thing: can you hear "more ice" and "less ice" in the piano, without pictures and without narration? About 5 minutes, headphones, silent switch off. There are no wrong feelings: if you cannot tell, say "about the same". Please do not enter a real name; use a code like L1.

Before you start

Learn the sound first (no scoring):

The piano plays more notes when there is more ice, and fewer when there is less.

Two short phrases of the same music. Which one has more ice?
